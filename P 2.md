# P2: Portfolio Repository with an Initial Commit

## Objective
To create a portfolio project and initialize a Git repository with an initial commit.

## Work Completed
- Created a `My-Portfolio` folder.
- Created an `index.html` file.
- Added basic portfolio content using HTML.
- Initialized Git using `git init`.
- Staged the file using `git add index.html`.
- Created the initial commit.

## Git Commands Used

```bash
git init
git status
git add index.html
git commit -m "Initial commit: Create portfolio"
git log --oneline
```

## Result
Successfully created a portfolio project and recorded its first version using Git.
