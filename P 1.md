# P1: Project Folder and Terminal Navigation

## Objective
To create a project folder and understand basic terminal navigation commands.

## Commands Used

### 1. Print Working Directory
```bash
pwd
```
Displays the current working directory.

### 2. List Files and Folders
```bash
ls
```
Displays the contents of the current directory.

### 3. Create a Directory
```bash
mkdir my-portfolio
```
Creates a new folder named my-portfolio.

### 4. Change Directory
```bash
cd my-portfolio
```
Moves into the specified directory.

### 5. Move to Parent Directory
```bash
cd ..
```
Moves one level up.

### 6. Create a File
```bash
touch index.html
```
Creates an empty HTML file.

## Result
Successfully created a project folder and practiced basic terminal navigation commands.
